# 质量门禁

交付前必须依次通过以下门禁。任一门禁失败时，先修复根因，再重新执行相关检查。

| 门禁 | 通过标准 | 建议动作 |
|---|---|---|
| 源内容 | HTML DOM 可见文字与 Markdown 归一化后的文字顺序一致 | 运行 `verify_resume.py`，禁止手工复制或改写内容 |
| 页面 | PDF 为用户要求的页数，默认 1 页；页面尺寸为 A4 | 调整密度档位、行高、间距和页边距，不删除文字 |
| PDF 内容 | PDF 可见字符数量与字符全集和源内容一致 | 使用 `pdftotext` 的结果做字符数量与多重集合检查 |
| 视觉 | 无裁切、重叠、孤行、异常换行、层级混乱或页底失衡 | 运行 `render_preview.py` 并查看所有交付页 |
| 交付 | PDF 可打印，HTML 可编辑，文件名清晰 | 交付 PDF 和 HTML；内部保留验证 JSON |

## 单页调优顺序

页面过长时，依次尝试 `elegant → balanced → compact`，随后小幅减少正文行高、项目间距、模块间距和页边距。页面下方留白过大时，反向调整：先增加正文行高、项目条目间距和模块间距，再小幅增加正文字号。每次调整后都要重新检查页数与预览。

## 原文一致性说明

Markdown 标题符号、列表符号、粗体标记、空白和分隔线属于结构标记，可以在渲染时转换。姓名、联系方式、日期、标点、数字、项目名称、技术词和正文句子属于可见文字，不得新增、删除、改写或替换。PDF 文本提取可能重排定位文本，因此最终验证同时检查 HTML DOM 顺序和 PDF 字符数量/字符全集。
