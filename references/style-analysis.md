# 参考样式分析

仅在用户提供参考 PDF、图片或现有简历时读取本文件。目标是提取视觉规则，而不是复制参考文档的文字。

## 分析顺序

先确认页数、页面尺寸和方向，再将参考 PDF 转为 220–300 DPI 图片。整页只用于判断总体结构；当文字密集或预览缩小时，按阅读顺序分块审阅。检查顶部留白、姓名位置、联系信息结构、正文边界、栏目顺序、页底留白和是否存在多栏。

随后识别字体体系。使用 `pdffonts` 查看嵌入字体；无法复用原字体时，选择字形与字重接近的已安装字体。中文技术简历优先采用 `Noto Sans CJK SC`，英文技术词可使用 `Noto Serif` 形成类似 PingFang SC + EB Garamond 的混排。不要猜字体名称，先用 `fc-match` 或 `fc-list` 确认。

最后记录颜色和层级。用户指定主题色时以该值为唯一强调色；模块标题、项目标题、关键词和主分隔线可使用主题色，正文使用深灰或黑色。避免渐变、阴影、卡片和大面积色块，除非参考文档明确采用这些元素。

## 布局复刻边界

参考文档只决定字体、字号、行高、缩进、标题线、留白和颜色等视觉属性。原始 Markdown 必须是唯一文字来源。不要从参考 PDF 抄入姓名、项目、日期、图标文本或其他内容；不要为了适配版面重写经历。

若参考文档是多页而用户要求单页，优先保持用户的页数约束。先调节正文行高、段落间距、列表缩进和模块间距，再小幅调整字号；不得通过删除或改写文字实现单页。
